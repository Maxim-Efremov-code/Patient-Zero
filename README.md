# Нулевой Пациент
## Описание
**Нулевой пациент** - это игра про выживание в зомби апокалипсисе. Вам предстоит спасти мир от неизвестной болезни и выжить среди зараженных. Игра от разработчика игры *"Катись или Проиграешь"*
## Управление
- W/A/S/D - движение
- Пробел - прыжок
- ПКМ - прицеливание
- ЛКМ - стрельба
- Кнопки 1-2/Колесико мыши - выбор оружия
## Дальнейшие обновления
- Лечение
- Количество патронов
- Новое оружие
- ИИ у зомби
- Гранаты
